### 1.1 边缘投影和分箱算法

**MATLAB 版本特点：**
- 使用精确的像素投影算法
- 每个像素根据边缘位置精确分配到超采样网格
- 线性插值到相邻超采样位置
- 精确的归一化和统计计数

**Python 版本特点：**
- 实现了与MATLAB一致的精确像素投影算法
- 每个像素根据边缘位置精确分配到超采样网格
- 线性插值到相邻超采样位置
- 精确的归一化和统计计数
- 修复了ESF在边界位置的异常数据

```python
def project2(self, bb, fitme, fac=4):
    # 精确投影算法 - 基于MATLAB版本
    for n in range(nlin):
        edge_pos = np.polyval(fitme, n)
        offset = edge_pos - (npix / 2)
        
        for j in range(npix):
            super_pos = (j - offset) * fac
            if 0 <= super_pos < nn:
                idx = int(super_pos)
                frac = super_pos - idx
                # 线性插值到相邻位置
                if idx < nn - 1:
                    esf[idx] += bb[n, j] * (1 - frac)
                    esf[idx + 1] += bb[n, j] * frac

# 边界异常修复
esf = esf[5:-5]  # 去除边界异常数据
```

```python
def tukey(self, n, alpha=0.5):
    # 精确的MATLAB算法
    first = int(np.floor(alpha * (n - 1) / 2.0)) + 1
    w[0:first] = 0.5 * (1 + np.cos(np.pi * (2 * x[0:first] / alpha - 1)))
    
    last = n - first + 1
    w[last-1:] = 0.5 * (1 + np.cos(np.pi * (2 * (1 - x[last-1:]) / alpha - 1)))
```
